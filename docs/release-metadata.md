# Required Release Metadata

Two repository-root files require maintainer decisions before the first public release.

## `LICENSE`

Choose a license for code authored in this repository. Confirm that commercial use,
redistribution, derivative works, patent rights, and clinical or research restrictions match
the intended project policy.

The root license does not replace upstream licenses for COLMAP, GLOMAP, SAM2, DeepSkin,
PointCleanNet, WoundAmbit, or their models and data.

## `CITATION.cff`

Add citation metadata after confirming the project title, author list, repository URL,
release version, release date, and any paper or DOI.

A minimal valid record includes `cff-version`, `message`, `title`, `authors`, and `version`.
Do not publish placeholder author names or an incorrect DOI.
